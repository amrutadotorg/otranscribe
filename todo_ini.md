# Tłumaczenia help-a15.innerHTML — transliteracja fonetyczna

**Źródło (EN):**
```
help-a15.innerHTML   = oTranscribe has <b>built-in phonetic input</b>. Go to <b>Settings</b> and enable <b>Phonetic input (transliteration)</b>, then choose your language. Type in Latin letters and press Space — the last word will be automatically replaced with your script (e.g. Devanagari, Arabic, Cyrillic).<br /><br />Alternatively, you can use the <a href="https://chromewebstore.google.com/detail/mclkkofklkfljcocdinagocijmpgbhab?utm_source=item-share-cb" target="_blank">Google Input Tools</a> Chrome extension for a virtual keyboard or additional phonetic options.
```

**Klucz do aktualizacji:** `help-a15.innerHTML` w każdym pliku `.ini`

**Instrukcja:** Poniżej propozycje tłumaczeń. Agent AI powinien je zweryfikować pod kątem:
1. Poprawności językowej (gramatyka, odmiana, interpunkcja)
2. Spójności z istniejącym stylem tłumaczeń w danym języku (porównaj z innymi kluczami `help-*`)
3. Zachowania tagów HTML (`<b>`, `<br />`, `<a>`) — nie tłumaczyć ich, nie usuwać
4. Nazwy "Settings" i "Phonetic input (transliteration)" — przetłumaczyć zgodnie z kluczami `settings` i `settings-phonetic-input-enabled` w danym języku

## Checklist dla agenta AI

Dla każdego pliku `.ini` zweryfikuj:

- [ ] Gramatyka i odmiana są poprawne
- [ ] Tagi HTML (`<b>`, `<br />`, `<a href="..." target="_blank">...</a>`) są nienaruszone
- [ ] Nazwy "Settings" i "Phonetic input (transliteration)" odpowiadają kluczom `settings` i `settings-phonetic-input-enabled` w danym języku
- [ ] Styl tłumaczenia jest spójny z istniejącymi kluczami `help-*` w tym języku
- [ ] Nie ma literówek ani błędów kodowania znaków

Po akceptacji: zaktualizuj `help-a15.innerHTML` w każdym pliku, uruchom `npm run build:locale` i zweryfikuj `public/data.ini`.
