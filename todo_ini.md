# Translation TODO — New Keys

Added in: `feat: add quick tutorial overlay for empty editor`

## Keys to translate

| Key | English (source) |
|-----|-----------------|
| `insertTimestamp` | Insert timestamp |
| `quick-tutorial-placeholder` | Enter your transcript here... |
| `quick-tutorial-heading` | Quick tips: |
| `quick-tutorial-italic` | {{mod}}+I adds italic formatting |
| `quick-tutorial-bold` | {{mod}}+B adds bold formatting |
| `quick-tutorial-playpause` | Press ESC to play/pause |
| `quick-tutorial-timestamp` | and {{mod}}+J to insert the current timestamp. |

**Note:** `{{mod}}` must be preserved as-is — it is replaced at runtime with ⌘ (Mac) or Ctrl (other platforms).
